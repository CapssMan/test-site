# Software Development Junior v1.0 — содержательная проверка

Дата: 19 августа 2026 года.

## Назначение

Язык-независимая диагностика сильного junior-разработчика. Тест проверяет инженерные решения вокруг кода, а не знание синтаксических мелочей одного языка или фреймворка. Формат — 40 оригинальных вопросов, 8 блоков по 5 вопросов, ориентир времени — 46 минут.

Тест не заменяет практическую задачу с написанием кода. Для найма разработчиков его следует использовать как первый сопоставимый сигнал, а следующий этап в будущем дополнить короткой задачей в браузерной песочнице с автоматическими тестами.

## Структура и сложность

| Блок | Вопросов | Что проверяется |
|---|---:|---|
| Алгоритмы и структуры данных | 5 | выбор структуры, границы, сложность |
| Код и проектирование | 5 | мутации, ответственность, ресурсы, конкурентное ожидание |
| Git и совместная работа | 5 | коммиты, revert, конфликты, review, утечка секрета |
| HTTP и API | 5 | методы, статусы, пагинация, повтор запроса |
| Базы данных | 5 | транзакции, ограничения, индексы, параметризация |
| Тестирование и диагностика | 5 | границы, интеграция, flaky-тесты, регрессии, логи |
| Безопасная разработка | 5 | authn/authz, серверный контроль, пароли, секреты, зависимости |
| Поставка и инженерная работа | 5 | требования, code review, CI, совместимые миграции, инциденты |

Распределение: 9 easy, 19 medium, 10 case, 1 calc, 1 hard. Позиции правильных вариантов после детерминированной сортировки: 10 / 12 / 10 / 8.

## Рыночная сверка

Текущее ядро российских junior-вакансий подтверждает востребованность Git, HTTP/REST, SQL и реляционных БД, unit-тестов, работы с API и code review. Для проверки границы использованы опубликованные вакансии hh.ru; их тексты не являются источником нормативных фактов и не копировались в вопросы.

Внешние assessment-платформы чаще разделяют language-agnostic problem solving и прикладные инженерные навыки. Поэтому SkillCheck сохраняет базовые алгоритмы, но не превращает весь тест в олимпиадные задачи: большая часть банка моделирует реальные инженерные решения junior-уровня.

## Ограничения и калибровка

До накопления реальных попыток сложность является экспертной гипотезой. После 30–50 валидных завершений следует проверить медианное время, долю правильных ответов и различающую способность каждого вопроса. Изменения ключей или содержания публиковать только новой версией банка.
