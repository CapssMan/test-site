# SkillCheck — остаток до финального MVP

Обновлено: 29 июля 2026 года после успешного IAM-only owner-smoke, исправления live-контракта YDB и переключения API Gateway на `assessment-v2` при закрытых pilot gates.

Уже работает assessment-ядро: пять тестов, закрытые ключи, server-side scoring, приглашения, отчёты, админ-аналитика, backup/recovery и исключение известных технических результатов. В Yandex Cloud работают YDB Serverless, раздельные read/write версии Cloud Function и API Gateway рейтинга. Кандидатский интерфейс умеет после подтверждённого успешного результата запросить отдельное согласие, опубликовать псевдоним и балл, сохранить ограниченный ключ управления и отозвать профиль. YDB автоматически удаляет профиль через 365 дней. Полный новый candidate backend прошёл live-цикл с 100% server-verified результатом и проверенным TXT; smoke-данные затем удалены до нулевого состояния. API Gateway уже использует `assessment-v2`, но публичный candidate frontend пока остаётся на Apps Script. Публичная база рейтинга остаётся пустой; mock-профили не создавались.

`SkillCheck` остаётся только рабочим названием. Доступность названия, домена, компании и товарного знака не подтверждалась и будет проверяться перед публичным брендингом.

## Осталось три проверяемых шага

Верхнеуровневых этапов всё ещё три только потому, что этап 18C закрывается после frontend/hosting cutover, а не после одной backend-проверки. Внутри 18C owner-smoke и backend Gateway cutover уже завершены; поэтому уменьшились часы, токены и число оставшихся проходов Codex.

| Шаг | Готовый результат | Часы | Токены | Режим |
|---|---|---:|---:|---|
| 18C | Переключение candidate frontend, публикация в Yandex Object Storage и rollback/QA; owner-smoke и backend Gateway cutover уже завершены | 3–7 | 15–35 тыс. | очень высокий до cutover, затем высокий |
| 19 | Пилот 10–30 завершений и одна сгруппированная версия исправлений | 8–15 + ожидание | 30–70 тыс. | высокий |
| 20 | Self-service запуск рейтинга, базовый employer shortlist, бренд/domain/legal launch-checklist | 8–12 | 30–50 тыс. | высокий; очень высокий для финального cutover |

Итого осталось примерно **19–34 часа**, **75–155 тыс. токенов** и **1–3 календарные недели пилота**. До технически готового российского MVP — ориентировочно **3–7 часов и 15–35 тыс. токенов**. Это оценка, а не обещание расхода: при отсутствии дефектов неизменённые части повторно не шлифуются.

До технического MVP ожидаются ещё **1–2 рабочих прохода Codex**: candidate frontend/Object Storage cutover с rollback и финальный QA. Owner-only закрытый smoke и backend Gateway cutover уже завершены. При отсутствии дефектов эти работы объединяются в один проход. Предположительно режим потребуется поменять ещё один раз: оставить **очень высокий** до cutover, затем перейти на **высокий** для финального QA и документации.

## Бесплатный контур и ограничения

- YDB ограничена 10 RU/с и 1 ГБ; бакеты — 100 МБ public и 1 ГБ private.
- Один Cloud Function resource содержит изолированные версии `read-v2`, `write-v2`, `admin-v1` и `assessment-v2`; рабочие версии используют 128 МБ, concurrency 1, без provisioned instances и логирования.
- Read service account имеет только `ydb.viewer`; writer — только `ydb.editor` на конкретную базу. Постоянных ключей нет.
- API Gateway имеет маршруты рейтинга, управления профилем, защищённой админки и gated assessment; логирование выключено.
- Бюджет `skillcheck-monthly` уведомляет на 30, 100 и 300 ₽, но не останавливает расход автоматически.
- Lockbox, CDN, VM, платный домен и другие платные дополнения не подключены.
- Перед новым потенциально платным сервисом владелец получает оценку и даёт отдельное разрешение.

## Что не растягиваем

- не повторяем аудит неизменённых банков без найденного дефекта;
- не пытаемся снова удалить девять исторических smoke-результатов;
- не строим платежи и сложный marketplace до работающего рейтинга;
- не отправляем письма, формы или сообщения от имени владельца;
- не называем рабочее имя юридически свободным без официальной проверки.
