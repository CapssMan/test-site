Предрелизный статус. Это согласие нельзя использовать для реальных кандидатов, пока не утверждён полный публичный адрес оператора, не решён вопрос уведомления Роскомнадзора и не завершены внешние legal/SME проверки. Российский production-контур и автоматические сроки хранения реализованы; backend дополнительно блокирует выпуск приглашений двумя независимыми gate.

Email для обращений по персональным данным: skillcheck.project@yandex.ru.

2. Согласие

Устанавливая отдельный флажок в форме SkillCheck, субъект свободно, своей волей и в своём интересе подтверждает согласие на обработку перечисленных ниже персональных данных для проведения одной контролируемой попытки тестирования. Отказ означает, что начать тест невозможно; иных неблагоприятных юридических последствий сам SkillCheck не создаёт.

3. Данные

  • имя, email и необязательный Telegram;
  • уровень английского, опыт и источник кандидата;
  • выбранный тест, ответы, время ответов и технические признаки прохождения;
  • результат, баллы, код результата, дата и время;
  • технический идентификатор браузера, данные приглашения и попытки; в постоянных служебных строках используются hash/HMAC и случайные идентификаторы вместо открытых значений.

4. Цели и действия

Цели: создать одноразовую попытку, проверить ответы на backend, сформировать и сохранить результат, ограничить повторные попытки, обеспечить восстановление отправки, защитить сервис от злоупотреблений и оценивать качество теста.

Действия: сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, псевдонимизация, блокирование, удаление и уничтожение с применением средств автоматизации.

5. Сервисы обработки

  • Yandex Object Storage — основной статический сайт, закрытые private banks, полные отчёты успешных результатов и краткоживущие резервные объекты;
  • Yandex API Gateway и Cloud Functions — приём запросов, проверка приглашения и серверная логика;
  • Yandex Managed Service for YDB — приглашения, попытки, результаты и технический журнал;
  • sessionStorage текущей вкладки — временное восстановление приглашения, попытки и отправки максимум на 6 часов.

Основной маршрут находится в российском контуре Yandex Cloud. GitHub Pages, Google Apps Script и Яндекс Диск сохранены только для технического rollback и не используются для реальных кандидатов без отдельного решения и новой версии документов.

6. Передача работодателю

Это согласие не разрешает передавать результат работодателю, контакты или отчёт, партнёру или неопределённому кругу лиц. Для добровольного рейтинга используется другое отдельное согласие, разрешающее публиковать только ограниченный набор полей. Для передачи дополнительных данных конкретному получателю потребуется отдельное согласие с его наименованием, целью, составом данных и сроком.

7. Срок и отзыв

Сроки: ответы, результат и полный отчёт — до 365 дней; завершённые приглашения и attempt/session — до 90 дней; технический журнал — до 365 дней; обычные резервные объекты — до 30 дней. Профиль рейтинга регулируется отдельным согласием, отзывом и пределом 365 дней без нового подтверждения.

Сроки в YDB применяются автоматическим TTL, а в закрытом Object Storage — lifecycle-правилами; временные пакеты и staging-объекты удаляются не позднее чем через 1 день.

Авторизованный администратор технически может удалить данные по коду результата после предварительной проверки. Публичный профиль рейтинга удаляется отдельно самим участником по ключу управления или по подтверждённому запросу оператору.

Согласие может быть отозвано обращением оператору по адресу skillcheck.project@yandex.ru. Этот же канал используется для запросов доступа, уточнения, блокирования и удаления. Отзыв не отменяет обработку, для которой у оператора после отзыва остаётся отдельное законное основание.

8. Автоматизированная оценка

Backend автоматически рассчитывает предварительный результат по ответам. SkillCheck не принимает решение о найме или отказе: результат должен оцениваться человеком вместе с собеседованием, опытом и другими материалами.

9. Подтверждение факта согласия

При начале попытки backend требует точную версию этого документа, отдельный флаг согласия и подтверждение 18+. В закрытой псевдонимизированной сессии фиксируются версия согласия и серверное время; открытые email, приглашение и токен там не сохраняются.
