# SkillCheck — остаток до финального MVP

Обновлено: 26 июля 2026 года после запуска российской read-основы рейтинга.

Уже работает assessment-ядро: пять тестов, закрытые ключи, server-side scoring, приглашения, отчёты, админ-аналитика, backup/recovery и исключение известных технических результатов. В Yandex Cloud дополнительно работают YDB Serverless, read-only Cloud Function и API Gateway рейтинга; публичная страница подключена к live API и не использует mock-профили.

`SkillCheck` остаётся только рабочим названием. Доступность названия, домена, компании и товарного знака не подтверждалась и будет проверяться перед публичным брендингом.

## Осталось четыре проверяемых шага

| Шаг | Готовый результат | Часы | Токены | Режим |
|---|---|---:|---:|---|
| 18B | Запись и отзыв opt-in профиля рейтинга, автоматические retention-сроки, закрытые write/admin API в YDB | 10–18 | 40–80 тыс. | очень высокий |
| 18C | Перенос candidate/admin write-path и отчётов, публикация frontend в Yandex Object Storage, cutover и rollback-проверка | 10–18 | 40–90 тыс. | очень высокий |
| 19 | Пилот 10–30 завершений и одна сгруппированная версия исправлений | 8–15 + ожидание | 30–70 тыс. | высокий |
| 20 | Self-service запуск рейтинга, базовый employer shortlist, бренд/domain/legal launch-checklist | 8–12 | 30–50 тыс. | высокий; очень высокий для финального cutover |

Итого осталось примерно **36–63 часа**, **140–290 тыс. токенов** и **1–3 календарные недели пилота**. Это оценка, а не обещание расхода: при отсутствии дефектов неизменённые части повторно не шлифуются.

## Бесплатный контур и ограничения

- YDB ограничена 10 RU/с и 1 ГБ; бакеты — 100 МБ public и 1 ГБ private.
- Cloud Function не имеет provisioned instances, использует 128 МБ и отключённое логирование.
- API Gateway имеет один read endpoint и отключённое логирование.
- Бюджет `skillcheck-monthly` уведомляет на 30, 100 и 300 ₽, но не останавливает расход автоматически.
- Lockbox, CDN, VM, платный домен и другие платные дополнения не подключены.
- Перед новым потенциально платным сервисом владелец получает оценку и даёт отдельное разрешение.

## Что не растягиваем

- не повторяем аудит неизменённых банков без найденного дефекта;
- не пытаемся снова удалить девять исторических smoke-результатов;
- не строим платежи и сложный marketplace до работающего рейтинга;
- не отправляем письма, формы или сообщения от имени владельца;
- не называем рабочее имя юридически свободным без официальной проверки.

Следующая задача: шаг 18B — безопасная запись и отзыв добровольного профиля рейтинга. Для него рекомендуется режим **очень высокий**.
